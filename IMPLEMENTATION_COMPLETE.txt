2. DATABASE TABLES CREATED
================================================================================

A. PRINTLOGS TABLE
-------------------
- log_id (INTEGER PRIMARY KEY AUTOINCREMENT)
- user_id (INTEGER NOT NULL) - FK to Users(u_id)
- recipe_id (INTEGER NOT NULL) - FK to Recipes(r_id)
- print_timestamp (TEXT NOT NULL)
- print_count (INTEGER DEFAULT 1)
- user_username (TEXT)
- recipe_title (TEXT)

B. PRINTSTATUS TABLE
--------------------
- ps_id (INTEGER PRIMARY KEY AUTOINCREMENT)
- user_id (INTEGER NOT NULL) - FK to Users(u_id)
- recipe_id (INTEGER NOT NULL) - FK to Recipes(r_id)
- last_printed (TEXT NOT NULL)
- total_prints (INTEGER DEFAULT 1)
- print_status (TEXT DEFAULT 'active')
- UNIQUE(user_id, recipe_id) - For upsert behavior
